# MD. Rafshan Jony — Portfolio

A modern, animated single-page portfolio for **MD. Rafshan Jony**, Sales Operations professional with 7+ years of FMCG experience.

## Features

- Dark / light mode (persisted)
- Animated gradient hero with floating blobs & particles
- Typing role text + animated counters
- Scroll-reveal animations (fade / left / right / scale)
- Card hover lift effects
- Responsive (mobile / tablet / desktop)
- Print-friendly

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- Lucide Icons
